# Creative Cloud — Social Media Content Agency Portfolio

A high-converting portfolio website for **Creative Cloud**, an elite social media content agency specializing in viral short-form videos (TikTok, Reels, Shorts), aesthetic brand feed curation, and high-ROAS paid social UGC creatives.

## 🚀 Key Features

### 1. Social Media Agency Portfolio Architecture
- **Hero Section**: Live social analytics telemetry dashboard (`24.8M Views This Month`, `1.2M Likes`, `+340% Follower Surge`).
- **Capabilities**: Short-Form Video Production, Viral Hook Scriptwriting, Aesthetic Grid Curation, Paid UGC Ads, Podcast Repurposing, Creator Seeding.
- **Curated Campaign Showcase**: Replaced generic text with *"Campaigns Launched. Audiences Captivated."* featuring real social media campaign metrics and click-to-view case study modal.
- **The Viral Formula (Process)**: 4-step workflow from Trend Discovery to Hook Engineering, 4K Filming, and Algorithmic Publishing.

### 2. High-Converting Meeting & Phone Call Scheduler (Replaced Pricing)
- **Interactive Calendar & Time Slots**: Clickable date pills (Mon Oct 6, Tue Oct 7...) and time selectors (10:00 AM, 2:00 PM, etc.).
- **Direct Click-to-Call Elements**: Direct phone number badges `(800) 845-2990` prominently placed in the navbar, hero, scheduler, and footer.
- **Interactive Booking Feedback**: Animated booking button with confirmation alert.

### 3. Upgraded SaaS Animations & Micro-Interactions
- **Global Ambient Mouse Spotlight**: Soft dynamic radiant light following the cursor across the entire page.
- **Enhanced Custom Cursor**: Center dot + spring-lerp trailing circle with magnetic pull and dynamic labels (`WATCH`, `SCHEDULE`, etc.).
- **Smooth Parallax Scroll Physics**: Floating stat badges smoothly translate with multi-speed parallax on scroll.
- **Scroll Reveals with Progressive Un-Blur**: Smooth translateY combined with blur-to-sharp transitions.
- **3D Specular Tilt**: High-impact perspective tilt with specular lighting on cards.
